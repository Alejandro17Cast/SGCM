# SGCM — Sistema de Gestión de Citas Médicas

## Requisitos
- XAMPP (Apache, PHP y MySQL) o entorno equivalente.
- Navegador moderno.

## Instalación local
1. Copiar la carpeta `SGCM` dentro de `htdocs`.
2. Iniciar Apache y MySQL desde XAMPP.
3. Crear una base de datos llamada `sgcm` en phpMyAdmin.
4. Ajustar `config/database.php` según las credenciales locales.
5. Abrir `http://localhost/SGCM/`.

## Estado inicial
- Identidad visual y paleta aplicadas.
- Login visual inicial.
- Selector de tema claro/oscuro con preferencia guardada en localStorage.
- Estructura inicial para backend PHP y conexión PDO.
- Autenticación y módulos funcionales aún pendientes.
